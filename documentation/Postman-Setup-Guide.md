# Postman Setup Guide

## Prerequisites
- Postman Desktop App installed
- Internet connection

## APIs Used in This Project

### 1. JSONPlaceholder
**Base URL:** https://jsonplaceholder.typicode.com  
**Documentation:** https://jsonplaceholder.typicode.com/guide/  
**Resources:** /posts, /comments, /users, /albums, /photos, /todos

### 2. ReqRes
**Base URL:** https://reqres.in/api  
**Documentation:** https://reqres.in/  
**Resources:** /users, /register, /login

### 3. DummyJSON
**Base URL:** https://dummyjson.com  
**Documentation:** https://dummyjson.com/docs  
**Resources:** /products, /auth/login, /products/search

## Setting Up Collections

### Step 1: Download Postman
1. Visit https://www.postman.com/downloads/
2. Download for Windows
3. Install and create account (optional)

### Step 2: Import Collections
1. Open Postman
2. Click 'Import' button
3. Select .json files from /postman-collections folder
4. Collections will appear in sidebar

### Step 3: Run Tests
1. Select a collection
2. Click on individual requests
3. Click 'Send' to execute
4. Verify response status and body
